# 01 — Dependency source of truth

**What to build:** A fresh clone on Ubuntu 24.04 builds a complete, reproducible Python environment with one command. `pyproject.toml` declares dependencies with platform markers and `uv.lock` pins them. `requirements.txt` keeps its current path and meaning but is regenerated by `uv export` rather than hand-edited, so the Windows `pip install -r` flow and `build_venv.bat` continue to work unchanged.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] `pyproject.toml` declares `openvino`, `onnxruntime`, `numpy`, `opencc-python-reimplemented`, `soundfile`, `soxr`, `scipy`, `kaldi-native-fbank`, `tokenizers` and `certifi` as direct runtime dependencies
- [ ] `segno` is an optional tunnel/QR extra and `sounddevice` is confined to a legacy desktop extra
- [ ] `librosa` is removed from the runtime dependency set
- [ ] `uv sync` on a clean Ubuntu 24.04 checkout produces an environment where every module above imports successfully
- [ ] `uv export` regenerates `requirements.txt` byte-identically to the committed file
- [ ] uv resolves against the system Python 3.12 rather than a downloaded interpreter
